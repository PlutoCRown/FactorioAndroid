# Factorio Android Launcher 0.3.13

## 游戏兼容与输入修复

- 新增高通 Adreno 图形兼容支持，修复已定位的黑屏、交换链透明度与透明混合问题。兼容路径针对高通专有 Vulkan 驱动，尚未覆盖所有型号与驱动版本的实机验证。
- 修复收起安卓输入法后游戏按钮无法点击，以及连续按返回键意外重新打开输入法的问题。
- 修复游戏退出后停留在最后一帧的问题，退出会话后自动返回启动器。
- 游戏已完成正常退出流程时，后续清理阶段的故障只保留诊断记录，不再显示异常退出提示。

## 日志与数据目录

- 实际异常退出后询问是否导出日志；点击“导出日志”即可通过系统文件选择器选择 ZIP 的保存位置。
- 设备信息页新增“打开日志文件夹”，保留最近 20 次会话的日志归档。
- 所有游戏版本，以及原版／Space Age，共用配置、存档与模组目录，更换安装包后继续使用同一份数据。

## 双指滚动

- 双指上下滑改为传递小数滚动量，不再由启动器累积到整格才发送。
- 同样滑动距离的滚动量减半，并反转原来的滚动方向。

## 已知问题

- 原生退出清理阶段仍可能产生异常，底层原因尚未完成修复；日志会保留原始故障与进程清理记录。

## 安装包

- `FactorioLauncher-0.3.13.apk`：标准包，通常选择此文件。
- `FactorioLauncher-0.3.13-YuanShen-sign.apk`：使用性能包应用 ID 的可选包，与标准包独立安装。
- `build-result.json`：本次构建的版本、包名和产物信息。
