# Factorio Android Launcher 0.3.20

本次发布汇总 0.3.13 之后的输入、配置和诊断改进。

## 屏幕虚拟手柄

- 新增 Compose 虚拟手柄，可在「启动设置」中开启，默认关闭。
- 提供双摇杆、十字键、ABXY、肩键、扳机、摇杆按下和菜单键，可展开额外手柄按键；LT／RT 支持锁定，方便组合操作。
- 支持多指同时操作、半透明显示与隐藏；切到后台或弹出输入法时自动松开按键。
- 沿用游戏的手柄绑定，启用时临时切换至手柄输入，结束后恢复原设置；支持与实体手柄合并输入。

## 鼠标与双指滚动

- 接入 Android 实体鼠标的悬停、移动、拖动、左中右键与横纵滚轮，坐标按游戏渲染分辨率换算。
- 实体鼠标不受「触屏模拟鼠标」开关影响；窗口失焦、切到后台或画面尺寸变化时释放按键。
- 双指滚动逐个转发有效触摸采样和历史采样，保留小数滚轮值，不等待整格或最小步长。
- 双指滚动灵敏度提高至 0.3.18 的 8 倍，默认每移动 24 dp 对应一格滚轮；与点击、长按右键和拖动手势互斥，减少误触。

## 游戏配置与退出提示

- 首次启动使用完整的游戏配置底稿，再覆盖路径、初始语言、画质与加载线程设置，避免简化配置缺少格式信息。
- 保留已有配置中的其他设置；缺少格式头时先备份再补齐，不强制替换已有格式版本。
- 结合本轮游戏日志、进程输出和退出顺序判断会话结果，不再单凭退出码 137 判定内存不足或引擎崩溃。
- 识别正常用户退出的 `Quitting: user-quit.` 与 `Goodbye`；之后的清理故障继续保留诊断记录，不再作为正常退出的异常提示。
- 未完成正常退出、原因尚不明确的进程中断会提供日志导出，保留进一步诊断所需的信息。

## 日志采集

- 修复同一会话重复导出日志时复用旧快照的问题；导出前刷新会话报告和系统退出历史。
- 引擎输出、进程退出结果和会话结果独立落盘，减少窗口关闭或界面线程来不及更新造成的信息缺失。
- 增加每秒内存采样、已采到的峰值和窗口主动清理标记，帮助区分内存回收、引擎故障与窗口退出清理。
- 日志按会话保存并限制大小和保留数量；导出旧会话时保留原会话内容。

## 文档与工程维护

- 更新中英文 README、运行要求、操作说明和实测数据，加入封面与项目状态徽章。
- 整理 Compose 页面、公共控件和主题，统一源码格式；测试迁移到 Gradle 标准目录。

## 已知问题

- 游戏在完成正常退出标记后，原生清理阶段仍可能出现故障；底层原因尚未定位，本版改进结果判断并保留原始诊断信息。
- 大地图、太空时代内容或切换星球表面仍可能产生较高内存压力；本版增强数据采集，不代表已经解决所有内存相关退出。

## 安装包

- `FactorioLauncher-0.3.20.apk`：标准包，通常选择此文件。
- `FactorioLauncher-0.3.20-YuanShen-sign.apk`：使用性能包应用 ID 的可选包，与标准包独立安装。
- `build-result.json`：本次构建的版本、包名和产物信息。

使用相同包名和签名覆盖安装可保留应用数据。游戏本体需自行从 Factorio 官网下载并导入。
