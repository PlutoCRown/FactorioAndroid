# Factorio Android Launcher 0.3.21

## 图形兼容性修复

- 修复部分天玑 / Mali 驱动无法初始化图形的问题。启动前查询实际 Vulkan 功能；缺少 dynamic rendering 或空描述符时，自动使用保留传统渲染路径的 Zink，无需用户切换兼容选项。
- 修复传统 Zink 的缓冲纹理上限计算整数溢出，解决本次复现的地形缺失、贴图条纹和移动物体残影。
- 修复传统呈现路径的红蓝通道、FIFO 呈现模式选择和输入附件用途协商。
- 能力足够的设备保持原有运行库选择，包括已有的高通透明混合修复；移除未解决问题的“Mali 图形兼容模式”开关。
- 传统运行库随 APK 交付，源码、补丁和完整构建命令已纳入工程，不需要玩家另外下载图形运行库。

## 日志与诊断

- 保留每轮图形初始化日志与 Surface 呈现记录，导出时汇总会话诊断信息。
- 记录 Vulkan 能力查询结果和实际选择的 Mesa 版本，帮助进一步排查其他驱动问题。

## English summary

This release addresses a Dimensity / Mali compatibility issue reproduced on a Redmi K50. The launcher now selects a traditional Zink rendering path when the Vulkan driver lacks dynamic rendering or null descriptors. Devices with the required features keep their existing runtime selection.

It also fixes an integer overflow in Zink's texel-buffer limit calculation that caused missing terrain, texture stripes and trails behind moving objects in the reproduced scenes, together with presentation-mode and color-format fixes. The ineffective Mali compatibility toggle has been removed; runtime selection is automatic.

The fix has been verified in the reproduced scenes. Other devices and driver versions may still need additional validation. If problems remain, please export a fresh session log from this version.

## 安装包 / Downloads

- `FactorioLauncher-0.3.21.apk`：标准包，通常选择此文件 / Standard package, recommended for most users.
- `FactorioLauncher-0.3.21-YuanShen-sign.apk`：可选的性能包应用 ID，与标准包独立安装 / Optional performance-package application ID; installs separately.
- `build-result.json`：本次构建的版本与产物信息 / Build version and artifact information.

相同包名、相同签名的覆盖安装可保留数据。游戏本体需自行从 Factorio 官网下载并导入。
