# Factorio Android Launcher 0.3.14

## 实体鼠标

- 接入 Android 实体鼠标的悬停、移动、拖动及左、中、右键，坐标随游戏渲染分辨率换算。
- 接入鼠标横向与纵向滚轮，保留小数滚动量；实体鼠标不受“触屏模拟鼠标”开关影响。
- 切到后台、窗口失焦或画面尺寸变化时释放按键，避免鼠标键卡住。

## 退出提示与日志

- 退出时同时读取本轮游戏日志与进程输出，识别已完成的正常退出流程。后续清理产生的 137 等退出码保留在诊断中，不再覆盖正常退出结果。
- 单凭非零退出码无法确认故障时，显示“游戏已结束，未能确认退出原因”，提供日志导出，不直接判定异常或内存不足。
- 明确的启动错误与运行故障仍提供错误提示和日志导出。
- 每次启动前将上一轮游戏日志保留为 `factorio-previous.log`，避免旧的退出记录影响新会话判断。

## 尚待确认

- 启动时的配置文件提示仍在调查，本版未修改配置生成逻辑。
- 实体鼠标和退出修复需要后续设备验证。
