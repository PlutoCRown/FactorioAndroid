# Factorio Android Launcher 0.3.15

## 退出判断与诊断

- 区分正常用户退出、运行故障与没有完成正常退出的进程中断，不再单凭退出码 137 判断内存不足或引擎崩溃。
- 按顺序识别 `Quitting: user-quit.` 和 `Goodbye`。之后发生的清理阶段故障继续保留在日志中，正常用户退出不弹异常退出窗口。
- 没有正常退出标记、进程以非零状态结束时，显示“游戏未正常退出，原因尚未确认”，提供日志导出。
- 会话报告明确记录用户退出标记、清理阶段故障、启动器主动终止的原因，以及应用版本和退出判断规则版本。

Goodbye 出现在引擎的全局对象销毁过程中，之后仍有原生清理。该阶段的 SIGSEGV 尚未定位到具体接口；本版调整会话分类与证据记录，没有宣称已修复底层故障。详见[退出判断与日志字段](../EXIT-DIAGNOSTICS.md)。

本版包含 0.3.14 的实体鼠标、完整配置底稿和其他修复。需要后续实机验证。
