# 游戏配置底稿与覆盖规则

首次运行的配置来自 `app/src/main/assets/config/default-config.ini`。这是完整游戏配置的文字底稿，保留游戏写出的格式头、区段、默认项说明和注释。准备底稿时删除了原有的活动偏好，包括绝对路径、语言、固定 UI 缩放、调试显示、按键修改、音量和图形测试设置；没有将这些偏好作为所有设备的默认值。

配置来源按以下顺序选择：已有用户配置、导入包内可用的 `config/config.ini`、启动器提供的配置底稿。启动前只更新 `[path]` 下的 `read-data`／`write-data`，在语言未设置时填写初始语言，并应用用户选择的画质与贴图加载线程上限。其他内容继续保留。选择“跟随游戏”时，保留相应的游戏设置。

底稿开头的 `; version=13` 是配置文件格式信息，不是 Factorio 的版本限制。已有配置的格式头会原样保留，不要求与底稿数字一致，也不会因此拒绝其他游戏版本。

游戏会独立检查文件开头注释中的 `version=`。旧启动器生成的无格式头配置会被当作旧格式，可能触发重置提示。对此先保留 `config.before-format-repair.ini` 备份，再从底稿补入格式头，保留原配置正文。已有格式头或根级 `config-version` 的配置不做这项修复。

更新底稿时，应使用游戏实际写出的完整配置，保留格式信息和默认项说明，移除个人路径及测试偏好，再检查覆盖后的新配置。底稿不是引擎版本白名单；游戏后续的格式迁移仍由游戏处理。
