# 贴图加载速度与内存

在“启动设置”里可以分别选择渲染分辨率、画质预设和“贴图加载线程上限”。修改在下次启动游戏时生效。

加载上限提供1、2、4、8、16、32和“跟随游戏设置”。默认1，优先减少加载阶段的内存峰值；有充足可用内存时可以逐级增加，观察加载耗时和稳定性。“跟随游戏设置”不覆盖配置文件里的现有值；如果之前已经写入1，这个选项会保留1，不会自动删除该值或恢复游戏默认。

这个设置对应游戏配置的`[graphics] max-sprite-loading-threads`，控制贴图准备阶段，不限制进入地图后的模拟或渲染线程。游戏还可能使用辅助线程：2.1.23中设置为1时，日志显示2个贴图加载工作线程。因此不要把这个数值理解为整个游戏允许使用的CPU核心数。

并发高时，多个工作线程会同时持有解码和处理中的贴图，加载可能更快，但内存峰值也会增加。设备内存不足时可能闪退，退出码为137。CPU或GPU性能强不代表可以承受更高峰值；可用内存、游戏包内容、模组、画质和其他应用占用都会影响结果。

画质预设提供4K贴图级、8K贴图级和16K贴图级，单张贴图图集上限分别为4096、8192和16384。4K与8K级使用中等素材，16K级使用高清素材；三档均启用高质量贴图压缩。图集上限不会强制所有图集达到该尺寸，实际大小取决于游戏内容。“使用游戏内设置”保留已有画质配置，线程上限仍可独立指定；两项都要由游戏配置决定时，也把线程上限设为“跟随游戏设置”。屏幕渲染分辨率与贴图素材质量是不同选项，使用中等素材时也可以保持100%屏幕分辨率。

一次12GB平板的太空时代2.1.23实测中，中等素材不压缩时，游戏日志估算纹理显存约3144MB，能够进入菜单，但建图时退出137。改成高质量压缩、加载上限1后，纹理显存估算降为约1133MB；100%分辨率下完成初始化和建图，玩家确认地图持续运行。进程RSS样本约2.9–3.2GiB。这只是该游戏内容和设备的一次验证，不是所有地图和模组的内存保证。

137通常对应进程被SIGKILL终止，单看退出码不能确定原因。本次失败同时有自身应用的系统OOM记录和较高内存占用，降低峰值后通过了原先失败的建图阶段，证据支持内存压力是主要原因。没有通过修改游戏引擎或删除游戏内容来解决。
