# 贴图加载速度与内存

在“启动设置”里可以分别选择渲染分辨率、贴图级别和“贴图加载线程上限”。修改在下次启动游戏时生效。

加载上限提供 1、2、4、8、16、32 和“跟随游戏设置”。默认 1，优先减少加载阶段的内存峰值；有充足可用内存时可以逐级增加，观察加载耗时和稳定性。“跟随游戏设置”不覆盖配置文件里的现有值；如果之前已经写入 1，这个选项会保留 1，不会自动删除该值或恢复游戏默认。

这个设置对应游戏配置的 `[graphics] max-sprite-loading-threads`，控制贴图准备阶段，不限制进入地图后的模拟或渲染线程。游戏可能另外使用辅助线程，因此该数值不等于整个游戏允许使用的 CPU 核心数。配置项是否被接受及实际线程数由导入的游戏版本决定。

并发高时，多个工作线程会同时持有解码和处理中的贴图，加载可能更快，内存峰值也可能增加。CPU 或 GPU 性能强不代表设备可以承受更高峰值；可用内存、原版／Space Age 内容、地图、模组、贴图质量和其他应用占用都会影响结果。

画质预设提供 4K、8K 和 16K 贴图级，单张图集上限分别为 4096、8192 和 16384。4K 与 8K 级选择中等素材，16K 级选择高清素材；三档选择高质量贴图压缩。图集上限不会强制所有图集达到该尺寸，实际大小取决于游戏内容和设备能力。GPU 加速压缩及 mipmap 压缩是否启用，由游戏的能力检测和自测决定，启动器不按设备型号强制关闭。

“使用游戏内设置”保留已有画质配置，线程上限仍可独立指定；两项都要由游戏配置决定时，也把线程上限设为“跟随游戏设置”。屏幕渲染分辨率与贴图素材质量是不同选项，使用中等素材时也可以保持 100% 屏幕分辨率。游戏负责自身 INI 格式版本，启动器不会以固定配置版本号拒绝启动。

内存不足可能导致进程被系统结束。退出码 137 通常表示收到 SIGKILL，单看这个退出码不能确定是内存不足；需结合系统和游戏日志判断。遇到加载或建图退出时，可以降低贴图级别和加载并发，并检查当前可用内存。这里不提供某个设备、地图或模组组合的内存与性能保证。
